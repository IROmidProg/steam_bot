# ربات استعلام قیمت بازی‌های استیم (aiogram + SQLAlchemy + SQLite)

## ساختار پروژه
```
steam_bot/
├── bot.py                     # نقطه ورود اصلی
├── config.py                  # تنظیمات (توکن، آیدی کانال، ...)
├── database/
│   ├── models.py              # مدل‌های SQLAlchemy (User, Game)
│   ├── engine.py               # engine و session async
│   └── crud.py                 # عملیات دیتابیس کاربر
├── keyboards/
│   ├── reply.py                 # کیبورد پایین صفحه (منوی اصلی / برگشت)
│   └── inline.py                 # کیبورد شیشه‌ای (عضویت، لیست بازی، لینک استیم)
├── middlewares/
│   └── subscription.py           # چک عضویت اجباری روی هر پیام/کالبک
├── services/
│   ├── steam_api.py               # ارتباط با API استیم + کش لیست بازی‌ها
│   └── fuzzy_search.py             # امتیازدهی شباهت اسم (برای rdd, غلط تایپی و ...)
├── states/
│   └── search_states.py             # وضعیت FSM جستجو
├── handlers/
│   ├── start.py                      # /start
│   ├── subscription.py                # دکمه «تایید عضویت»
│   └── search.py                       # جستجو بازی + نمایش جزئیات
├── utils/
│   └── texts.py                         # متن‌های ربات
├── requirements.txt
└── .env.example
```

## نصب و راه‌اندازی

```bash
cd steam_bot
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# داخل .env توکن ربات رو بذار: BOT_TOKEN=...
```

سپس:
```bash
python bot.py
```

اولین بار که ربات بالا میاد، کل لیست بازی‌های استیم (از `GetAppList`) رو می‌گیره و توی `bot.db` (SQLite) کش می‌کنه — این لیست حدود ۱۵۰ هزار آیتم داره پس ممکنه چند ثانیه تا چند ده ثانیه طول بکشه؛ دفعات بعد چون از قبل توی دیتابیس هست، این مرحله رد می‌شه.

## نکات مهم و پیش‌نیازها

1. **ربات باید ادمین کانال `@bot_resume` باشه**، وگرنه نمی‌تونه با `get_chat_member` وضعیت عضویت کاربر رو چک کنه.
2. **رنگ دکمه‌ها از طریق Bot API قابل تنظیم نیست.** تلگرام هیچ پارامتری برای رنگ پس‌زمینه دکمه‌های Inline یا Reply در اختیار بات نمی‌گذارد؛ رنگ کاملاً به تنظیمات کلاینت کاربر (تلگرام‌دسکتاپ، موبایل، وب) بستگی دارد. برای شبیه‌سازی همون حس بصری که خواسته بودی:
   - دکمه «تایید عضویت» → با ایموجی ✅ (سبز)
   - دکمه «برگشت به صفحه اصلی» → با ایموجی 🔴 (قرمز)
3. **جستجوی فازی** (`services/fuzzy_search.py`) با ترکیب چند الگوریتم rapidfuzz (WRatio، token_sort_ratio، partial_ratio) + مقایسه با مخفف حروف اول کلمات (acronym) کار می‌کنه؛ به همین خاطر چیزی مثل `rdd` هم به Red Dead Redemption و هم به Red Dead Redemption 2 نزدیک امتیاز می‌گیره و هر دو توی لیست میان. آستانه امتیاز (`FUZZY_SCORE_THRESHOLD`) و تعداد نتایج (`SEARCH_RESULTS_LIMIT`) توی `config.py` قابل تغییرن.
4. **قیمت‌ها بر اساس ریجن `STEAM_CC`** (پیش‌فرض `us`) از `appdetails` گرفته می‌شن. برای قابلیت «مقایسه قیمت در ریجن‌های مختلف» (که طبق گفته‌ی خودت بعداً تکمیلش می‌کنی) کافیه همین تابع `get_app_details` رو با چند کد کشور مختلف صدا بزنی.
5. سه دکمه‌ی «بازی‌های رایگان‌شده»، «مقایسه قیمت» و «اخبار بازی‌ها» فعلاً فقط پیام «به‌زودی فعال می‌شه» می‌دن — طبق چیزی که گفتی، این‌ها رو خودت بعداً تکمیل می‌کنی.

## رفرش دستی لیست بازی‌ها (اختیاری)

اگه بعد از مدتی خواستی لیست بازی‌های استیم رو کامل به‌روزرسانی کنی (بازی‌های جدید اضافه شده)، می‌تونی از تابع `refresh_game_cache` در `services/steam_api.py` استفاده کنی؛ مثلا با ساختن یک کامند ادمین که همین تابع رو صدا بزنه.

## جریان کار ربات

1. هر پیام/کالبک کاربر → میدل‌ور `SubscriptionMiddleware` چک عضویت انجام می‌ده.
2. عضو نبود → پیام عضویت اجباری + دو دکمه (لینک کانال / تایید عضویت).
3. زد روی «تایید عضویت» → دوباره چک می‌شه؛ عضو نبود Popup ارور (`show_alert=True`)، عضو بود پیام خوش‌آمد + منوی اصلی.
4. `/start` → ذخیره/آپدیت کاربر در دیتابیس + نمایش منوی اصلی (۴ دکمه).
5. «جستجو بازی» → کیبورد پایین صفحه با «برگشت به صفحه اصلی» جایگزین می‌شه + پیام «اسم بازی رو بفرست».
6. کاربر اسم بازی رو می‌فرسته → جستجوی فازی روی کش محلی بازی‌های استیم → لیست دکمه‌های اینلاین (فقط اسم بازی).
7. کاربر روی اسم بازی می‌زنه → عکس بنر + کپشن کامل مشخصات (قیمت، ژانر، سازنده، تاریخ انتشار، توضیح کوتاه) + دکمه لینک به صفحه استیم.
8. تا وقتی کاربر «برگشت به صفحه اصلی» رو نزنه، همون کیبورد پایین صفحه (دکمه برگشت) باقی می‌مونه و می‌تونه بازی‌های بیشتری هم سرچ کنه.
